# Настройки

## Настройки пользователя

### Профиль пользователя

После входа в систему вы можете viewing информацию о своем профиле:

- **Имя** — отображается в списке документов как автор
- **Email** — используется для входа в систему
- **Дата регистрации** — когда был создан аккаунт

### Изменение пароля

Для изменения пароля:

1. В当前版本 функция изменения пароля недоступна через интерфейс
2. Для сброса пароля обратитесь к администратору системы

## Настройки приложения

### Язык интерфейса

Приложение полностью локализовано на русский язык. В=current version переключение языков недоступно.

### Тема оформления

Приложение поддерживает светлую и темлую темы, автоматически определяя настройки операционной системы.

### Размер окна

Приложение remembers размер окна при закрытии и восстанавливает его при следующем запуске.

## Настройки базы данных

### Резервное копирование

Данные хранятся в локальной SQLite базе данных. Для создания резервной копии:

1. Найдите файл базы данных в папке приложения
2. Скопируйте файл в безопасное место

### Восстановление из резервной копии

1. Закройте приложение
2. Замените файл базы данных резервной копией
3. Запустите приложение

:::warning
При восстановлении из резервной копии все данные, созданные после момента копирования, будут потеряны.
:::

## Настройки безопасности

### Хэширование паролей

Все пароли хранятся в захэшированном виде с использованием bcrypt.

### Целостность версий

Система автоматически проверяет целостность истории версий через хэширование.

### Ролевой доступ

Права доступа определяются ролью пользователя:

- **Сотрудник** — только свои черновики
- **Руководитель** — согласование и отклонение документов
- **Администратор** — полный доступ
