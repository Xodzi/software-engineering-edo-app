# Введение

Добро пожаловать в руководство пользователя СЭД (Система электронного документооборота)!

СЭД — это десктопное приложение для управления документами организации с поддержкой версионирования и workflow согласования. Приложение построено на технологии Electron и предназначено для локального использования.

## Основные возможности

- **Управление документами** — создание, редактирование, удаление документов
- **Версионирование** — автоматическое сохранение всех изменений с возможностью просмотра и сравнения версий
- **Согласование документов** — workflow утверждения с ролями (Сотрудник, Руководитель, Администратор)
- **Прикрепление файлов** — загрузка и управление вложениями к документам
- **Целостность версий** — контроль неизменяемости через хэширование
- **Поиск и фильтрация** — быстрый поиск документов по содержимому и статусу

## Архитектура системы

Приложение использует следующие технологии:

- **Electron** — десктопный контейнер
- **React** — пользовательский интерфейс
- **Vite** — сборка и разработка
- **MobX** — управление состоянием
- **SQLite** — локальная база данных
- **Drizzle ORM** — работа с базой данных
