# Работа с документами

## Просмотр документа

Для просмотра документа нажмите на его название в списке документов.

![Детальный просмотр документа](/img/screenshots/Детальный%20просмотр%20документа.png)

### Структура страницы документа

#### Заголовок документа

- **Название документа** — отображается крупным шрифтом
- **Статус** — цветовой индикатор с названием статуса
- **Количество версий** — общее число сохраненных версий
- **Автор** — имя создателя документа

#### Панель метаданных

Справа от заголовка расположена информация:

- **Автор** — кто создал документ
- **Создан** — дата и время создания
- **Обновлен** — дата и время последнего изменения
- **Исходная версия** — ссылка на исходную версию (если создана из старой версии)

#### Содержание документа

Основная часть страницы — текст документа, отображаемый в блоке `<pre>`.

## Создание документа

1. На главной странице нажмите «Создать документ»
2. Заполните форму:
   - **Название** — обязательно
   - **Содержание** — текст документа
3. Нажмите «Сохранить»
4. Документ будет создан со статусом «Черновик»

![Создание документа](/img/screenshots/Создание%20документа.png)

## Редактирование документа

Документы со статусом «Черновик» можно редактировать:

1. Откройте документ для просмотра
2. Нажмите кнопку «Изменить»
3. В открывшемся диалоге внесите изменения:
   - **Название** — можно изменить
   - **Содержание** — можно изменить
   - **Причина изменений** — обязательно укажите причину редактирования
4. Нажмите «Сохранить»

![Изменение документа](/img/screenshots/Изменение%20документа.png)

:::note
При каждом сохранении создается новая версия документа. Старые версии остаются в истории.
:::

## Удаление документа

Документы со статусом «Черновик» можно удалить:

1. Откройте документ для просмотра
2. Нажмите кнопку «Удалить»
3. Подтвердите удаление в появившемся диалоге

:::warning
Удаление документа необратимо. Все версии и вложения будут удалены.
:::

## Статусы документов

| Статус | Описание | Доступные действия |
|--------|----------|-------------------|
| **Черновик (DRAFT)** | Незавершенный документ | Редактирование, удаление, отправка на согласование |
| **На согласовании (PENDING)** | Ожидает утверждения | Согласование, отклонение |
| **Утвержден (APPROVED)** | Утвержден руководством | Только просмотр |
| **Отклонен (REJECTED)** | Отклонен при согласовании | Только просмотр |
| **В архиве (ARCHIVED)** | Архивный документ | Только просмотр |
