# Основные функции приложения

## Версионирование документов

Система автоматически сохраняет все изменения документа в виде версий.

### Просмотр истории версий

В детальном просмотре документа в нижней части страницы находится таблица с историей версий:

![Список версий документа](/img/screenshots/список%20версий%20документа.png)

Каждая версия содержит:
- **Номер версии** — порядковый номер
- **Автор** — кто внес изменения
- **Дата** — когда была создана версия
- **Причина изменений** — комментарий к изменениям

### Сравнение версий

Для сравнения двух версий документа:

1. Выберите версию из таблицы
2. Нажмите «Просмотреть различия»
3. Откроется окно side-by-side сравнения

![Просмотр документа со статистикой версий](/img/screenshots/Также%20просмотр%20документа%20со%20статистикой%20версий.png)

![Side-by-side просмотр изменений](/img/screenshots/sidy%20by%20side%20просмотр%20изменений%20версий%20документа.png)

#### Статистика изменений

В окне сравнения отображается:
- **Идентичные строки** — количество неизмененных строк
- **Добавленные строки** — количество новых строк (отмечены зеленым)
- **Удаленные строки** — количество удаленных строк (отмечены красным)
- **Измененные строки** — количество измененных строк (отмечены желтым)

#### Алгоритм сравнения

Система использует алгоритм LCS (Longest Common Subsequence) для определения минимального набора изменений между версиями.

### Восстановление версии

Вы можете вернуть документ к любой предыдущей версии:

1. Откройте окно сравнения версий
2. Нажмите «Восстановить версию»
3. Подтвердите действие

:::note
При восстановлении создается новая версия с содержимым восстановленной версии. Старые версии не удаляются.
:::

### Создание документа из версии

Вы можете создать новый документ на основе любой версии:

1. Откройте окно сравнения версий
2. Нажмите «Создать черновик из версии»
3. Откроется форма создания документа с предзаполненным содержимым
4. Отредактируйте и сохраните новый документ

## Согласование документов

Система поддерживает workflow согласования документов с ролями.

### Роли в системе

| Роль | Описание | Права |
|------|----------|-------|
| **Сотрудник (EMPLOYEE)** | Обычный пользователь | Создание, редактирование черновиков, отправка на согласование |
| **Руководитель (MANAGER)** | Руководитель отдела | Все права сотрудника + согласование и отклонение документов |
| **Администратор (ADMINISTRATOR)** | Системный администратор | Полные права на управление документами |

### Процесс согласования

![Просмотр документа и функции согласования](/img/screenshots/Просмотр%20документа%20и%20функции%20согласования%20документа%20видно%20возможные%20роли.png)

#### 1. Отправка на согласование

Только документы со статусом «Черновик» можно отправить на согласование:

1. Откройте документ
2. Выберите роль (Сотрудник/Руководитель/Администратор)
3. Нажмите «Отправить на согласование»
4. Статус изменится на «На согласовании»

#### 2. Согласование документа

Для согласования документа необходимо иметь роль «Руководитель» или «Администратор»:

1. Откройте документ со статусом «На согласовании»
2. Выберите свою роль
3. Нажмите «Согласовать»
4. Статус изменится на «Утвержден»

#### 3. Отклонение документа

Для отклонения документа:

1. Откройте документ со статусом «На согласовании»
2. Выберите свою роль
3. Нажмите «Отклонить»
4. Введите причину отклонения в появившемся диалоге
5. Подтвердите отклонение
6. Статус изменится на «Отклонен»

### Целостность версий

Система использует хэширование для контроля целостности истории версий:

- Каждая версия содержит **content_hash** — SHA-256 хэш содержимого
- Каждая версия содержит **history_hash** — SHA-256 хэш метаданных версии + предыдущий history_hash
- Система автоматически проверяет целостность цепочки хэшей
- При обнаружении несоответствия отображается предупреждение

## Управление вложениями

К документам можно прикреплять файлы (максимум 10 МБ).

### Просмотр вложений

В детальном просмотре документа находится раздел «Вложения»:

![Дополнительные файлы к документу](/img/screenshots/дополнительные%20файлы%20к%20документу%20attachmets.png)

### Загрузка вложений

1. Откройте документ со статусом «Черновик»
2. В разделе «Вложения» нажмите «Добавить файл»
3. Выберите файл на компьютере
4. Файл будет загружен и отображен в списке вложений

### Скачивание вложений

1. В списке вложений нажмите кнопку скачивания рядом с нужным файлом
2. Файл будет сохранен на компьютер

### Удаление вложений

1. В списке вложений нажмите кнопку удаления рядом с нужным файлом
2. Подтвердите удаление

:::note
Управлять вложениями можно только для документов со статусом «Черновик».
:::
