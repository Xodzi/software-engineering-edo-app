# Навигация

Приложение использует хэш-роутинг для навигации между страницами.

## Основные маршруты

| Маршрут | Страница | Описание |
|---------|----------|----------|
| `#/login` | Страница входа | Форма авторизации |
| `#/register` | Стига регистрации | Форма создания нового аккаунта |
| `#/` | Список документов | Главная страница со всеми документами |
| `#/document/{id}` | Детальный просмотр | Полная информация о документе |

## Навигация между страницами

### Из списка документов

- **Клик по названию документа** — переход к детальному просмотру
- **Кнопка «Создать документ»** — открытие формы создания

### Из детального просмотра

- **Кнопка «Назад к списку»** — возврат к главной странице
- **Ссылка в логотипе** — возврат на главную страницу

### Из формы входа/регистрации

- **Ссылка «Зарегистрироваться»** — переход к форме регистрации
- **Ссылка «Войти»** — переход к форме входа

## Индикация текущей страницы

- **Активный пункт меню** — выделяется цветом в навигационной панели
- **Хэш URL** — определяет текущую страницу

## Возврат к списку документов

Из любого экрана вы можете вернуться к списку документов:

1. Нажмите кнопку «Назад к списку» (если доступна)
2. Или нажмите на логотип «СЭД» в верхней панели
3. Или введите адрес `#/` в адресной строке
