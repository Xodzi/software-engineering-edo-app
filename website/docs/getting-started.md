# Начало работы

## Системные требования

- Операционная система Windows 10/11, macOS или Linux
- Минимум 4 ГБ оперативной памяти
- Свободное дисковое пространство: 500 МБ

## Установка приложения

### Для разработчиков

1. Убедитесь, что установлен Node.js версии 18 или выше
2. Склонируйте репозиторий проекта
3. Установите зависимости:
   ```bash
   npm install
   ```
4. Выполните重建 native-модулей:
   ```bash
   npm run rebuild
   ```
5. Настройте базу данных:
   ```bash
   npm run db:setup
   ```

### Запуск приложения

Для запуска в режиме разработки:
```bash
npm run dev
```

Для сборки продакшн-версии:
```bash
npm run build
```

## Первый запуск

При первом запуске приложения вы увидите страницу входа. Для начала работы необходимо зарегистрироваться.

![Страница входа](/img/screenshots/Страница%20входа.png)

## Регистрация нового пользователя

1. На странице входа нажмите ссылку «Зарегистрироваться»
2. Заполните форму регистрации:
   - **Имя** — ваше имя
   - **Email** — рабочий email
   - **Пароль** — минимум 6 символов
   - **Подтверждение пароля** — повторите пароль

![Страница регистрации](/img/screenshots/Страница%20регистрации.png)

3. Нажмите «Зарегистрироваться»
4. После успешной регистрации вы будете автоматически перенаправлены на главную страницу

## Вход в систему

Если вы уже зарегистрированы:

1. Введите email и пароль на странице входа
2. Нажмите «Войти»
3. При успешной авторизации откроется главная страница со списком документов
