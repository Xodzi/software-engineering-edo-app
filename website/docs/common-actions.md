# Часто встречающиеся действия

## Создание и отправка документа на согласование

### Сценарий 1: Создание нового документа

1. Нажмите «Создать документ» на главной странице
2. Заполните название и содержание
3. Нажмите «Сохранить»
4. Документ создан со статусом «Черновик»

### Сценарий 2: Отправка документа на согласование

1. Откройте документ со статусом «Черновик»
2. Выберите роль «Сотрудник»
3. Нажмите «Отправить на согласование»
4. Статус изменится на «На согласовании»

### Сценарий 3: Согласование документа

1. Откройте документ со статусом «На согласовании»
2. Выберите роль «Руководитель» или «Администратор»
3. Нажмите «Согласовать»
4. Статус изменится на «Утвержден»

### Сценарий 4: Отклонение документа

1. Откройте документ со статусом «На согласовании»
2. Выберите роль «Руководитель» или «Администратор»
3. Нажмите «Отклонить»
4. Введите причину отклонения
5. Подтвердите действие
6. Статус изменится на «Отклонен»

## Работа с версиями

### Сценарий 5: Просмотр истории изменений

1. Откройте документ
2. Прокрутите страницу вниз до раздела «История версий»
3. Просмотрите таблицу с версиями

### Сценарий 6: Сравнение двух версий

1. В таблице версий найдите нужную версию
2. Нажмите «Просмотреть различия»
3. Просмотрите side-by-side сравнение
4. Изучите статистику изменений

### Сценарий 7: Восстановление предыдущей версии

1. Откройте окно сравнения версий
2. Нажмите «Восстановить версию»
3. Подтвердите действие
4. Будет создана новая версия с восстановленным содержимым

### Сценарий 8: Создание нового документа из старой версии

1. Откройте окно сравнения версий
2. Нажмите «Создать черновик из версии»
3. Отредактируйте предзаполненную форму
4. Сохраните новый документ

## Работа с вложениями

### Сценарий 9: Загрузка файла к документу

1. Откройте документ со статусом «Черновик»
2. В разделе «Вложения» нажмите «Добавить файл»
3. Выберите файл на компьютере (максимум 10 МБ)
4. Файл появится в списке вложений

### Сценарий 10: Скачивание вложения

1. В списке вложений найдите нужный файл
2. Нажмите кнопку скачивания
3. Файл сохранится на компьютер

### Сценарий 11: Удаление вложения

1. В списке вложений найдите нужный файл
2. Нажмите кнопку удаления
3. Подтвердите удаление

## Поиск документов

### Сценарий 12: Быстрый поиск документа

1. На главной странице введите текст в поле поиска
2. Список документов автоматически отфильтруется
3. Нажмите на найденный документ для просмотра

### Сценарий 13: Фильтрация по статусу

1. На главной странице выберите статус в выпадающем списке
2. Список документов отфильтруется по выбранному статусу
3. Для сброса фильтра выберите «Все статусы»

## Управление аккаунтом

### Сценарий 14: Выход из системы

1. В правом верхнем углу нажмите на имя пользователя
2. Выберите «Выйти»
3. Вы будете перенаправлены на страницу входа

### Сценарий 15: Смена пользователя

1. Выйдите из текущей учетной записи
2. Войдите под другим аккаунтом
