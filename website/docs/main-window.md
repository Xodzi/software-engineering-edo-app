# Главное окно приложения

После входа в систему вы попадаете на главную страницу — список документов.

![Главная страница - список документов](/img/screenshots/Главная%20страница%20список%20документов.png)

## Структура главной страницы

### Верхняя панель (Hero)

В верхней части страницы отображается:

- **Название раздела** — «Документы»
- **Краткое описание** — «Управление документами и согласование»
- **Кнопка «Создать документ»** — для создания нового документа

### Панель метрик

Под описанием расположены карточки с основными показателями:

- **Всего документов** — общее количество документов в системе
- **Черновиков** — количество документов со статусом «Черновик»
- **Состояние загрузки** — индикатор загрузки данных

### Таблица документов

Основная часть страницы — интерактивная таблица со списком документов:

| Столбец | Описание |
|---------|----------|
| **Название** | Название документа (ссылка для перехода к детальному просмотру) |
| **Статус** | Текущий статус документа (с цветовым индикатором) |
| **Автор** | Имя создателя документа |
| **Версия** | Номер текущей версии |
| **Создан** | Дата и время создания |
| **Обновлен** | Дата и время последнего изменения |

## Фильтрация и поиск

Над таблицей документов расположены элементы управления:

### Поиск

- Поле для ввода текста для поиска
- Поиск выполняется по всем полям: название, содержание, автор, статус
- Результаты обновляются в реальном времени по мере ввода

### Фильтр по статусу

Выпадающий список для фильтрации по статусу:

- **Все статусы** — показать все документы
- **Черновик (DRAFT)** — незавершенные документы
- **На согласовании (PENDING)** — документы, ожидающие утверждения
- **Утвержден (APPROVED)** — утвержденные документы
- **Отклонен (REJECTED)** — отклоненные документы
- **В архиве (ARCHIVED)** — архивные документы

## Создание нового документа

1. Нажмите кнопку «Создать документ» в верхней части страницы
2. Откроется модальное окно с формой создания

![Создание документа](/img/screenshots/Создание%20документа.png)

3. Заполните поля:
   - **Название документа** — обязательно для заполнения
   - **Содержание** — текст документа
4. Нажмите «Сохранить»
5. Документ появится в списке со статусом «Черновик»
