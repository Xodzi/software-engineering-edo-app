# Руководство пользователя СЭД

Это руководство пользователя для Системы электронного документооборота (СЭД).

## Запуск документации

### Для разработчиков

1. Установите зависимости:
   ```bash
   npm install
   ```

2. Запустите сервер разработки:
   ```bash
   npm run docs:start
   ```

3. Откройте браузер по адресу: http://localhost:3000

### Запуск вместе с приложением

Для запуска одновременно приложения и документации:

```bash
npm run start:all
```

## Сборка для продакшена

Для сборки статической версии документации:

```bash
npm run docs:build
```

Собранные файлы будут位于 `website/build/` папке.

## Структура документации

Документация organized по следующим разделам:

1. **Введение** — обзор системы
2. **Начало работы** — установка и первый запуск
3. **Главное окно приложения** — обзор интерфейса
4. **Навигация** — перемещение по приложению
5. **Работа с документами** — создание и управление документами
6. **Основные функции** — версионирование, согласование, вложения
7. **Настройки** — конфигурация приложения
8. **Часто встречающиеся действия** — типовые сценарии работы
9. **Возможные ошибки и их решения** — решение проблем

## Добавление нового контента

Для добавления новой страницы:

1. Создайте Markdown файл в `website/docs/`
2. Добавьте страницу в `website/sidebars.ts`
3. Перезапустите сервер разработки

## Контрибуция

Для внесения изменений в документацию:

1. Fork репозиторий
2. Создайте ветку для изменений
3. Внесите изменения
4. Отправьте pull request
